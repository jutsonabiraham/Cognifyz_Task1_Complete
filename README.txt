COGNIFYZ FULL STACK DEVELOPMENT - TASK 1

Task:
HTML Structure and Basic Server Interaction

Requirements covered:
1. HTML structure with forms for user input.
2. Node.js server using Express.
3. Server-side endpoint to handle form submission.
4. EJS server-side rendering to dynamically generate HTML.

HOW TO RUN

1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run:
   npm install

4. Run:
   npm start

5. Open:
   http://localhost:3000

FILES

server.js          Express server and POST endpoint
views/index.ejs    EJS dynamic HTML page
public/style.css   Page styling
package.json       Project configuration

FORM ENDPOINT

GET  /
POST /submit
